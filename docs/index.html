What We're Building

Our roadmap is ambitious. We aren't just making another tool; we're building a highly optimized, community-owned platform for 3D artists. Here is what we aim to deliver with your support.

  • Create and customize 3D characters with advanced morphing and rigging tools
  • Import environments, props, and assets to build complete scenes
  • Pose and animate characters with intuitive controls and modern IK systems
  • Set up lighting, cameras, and composition inside a unified workspace
  • Render final images without switching tools or using external applications

Next-Gen Rigging

We are designing an intuitive node-based architecture for advanced IK/FK, modular bone generation, and painless weight painting.

Fluid Animation

Planning a robust, non-linear animation timeline featuring precise curve editors and seamless sequence blending for animators.

Real-Time Viewport

Integrating modern physically based rendering (PBR) so you can pose and animate with instant, high-fidelity visual feedback.

Pipeline Friendly

Committing to strict open standards. We aim for native, flawless support for glTF, FBX, and direct integration with major game engines.

The Manifesto

The 3D software landscape shouldn't be locked behind expensive proprietary walls or convoluted licensing. We are starting PoseStudio because the community deserves a dedicated, modern tool for character work that respects user freedom.

Free Forever

PoseStudio will be 100% open-source from day one until the end of time. No hidden paywalls, no feature gating.

Built By You

We are laying the foundation, but the community will build the house. Development happens in the open on GitHub.

Your Data is Yours

PoseStudio's core philosophy revolves around standard, accessible, and interoperable file formats.
